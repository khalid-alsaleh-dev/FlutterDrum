# Flutter Drum

A simple interactive drum app built with Flutter.

## Tech stack

- Flutter
- Dart

## Run locally

1. Install the Flutter SDK.
2. Clone this repository:
   `git clone https://github.com/khalid-alsaleh-dev/FlutterDrum.git`
3. Install dependencies and launch:
   `cd FlutterDrum`
   `flutter pub get`
   `flutter run`
